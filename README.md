# 📊 Customer Sales SQL Analytics Project

## 📌 Project Overview

This project focuses on analyzing retail sales data using SQL to generate business insights from customer, order, and order item data.

The objective of this project is to solve real-world business problems related to customer behavior, sales performance, product analysis, customer retention, and revenue trends using advanced SQL techniques.

The analysis was performed using three relational tables:

- Customers
- Orders
- Order Items

---

# 🗂️ Database Tables

## Customers Table

Contains customer information:

- Customer ID
- Customer Name
- Customer Segment
- Registration Date
- Location Details

## Orders Table

Contains order transaction details:

- Order ID
- Customer ID
- Order Date
- Order Status
- Payment Method
- Order Amount

## Order Items Table

Contains product-level information:

- Order ID
- Product Name
- Category
- Quantity
- Unit Price
- Discount

# 💼 Business Requirements Solved

## Level 1: Basic SQL Analysis

### Customer Order Summary
- Calculated total orders, total spending, and average order value for each customer.
- Included customers with no orders using LEFT JOIN.

### Category Performance
- Analyzed revenue generated by each product category.
- Filtered categories with revenue greater than $500.

### Monthly Sales Trend
- Calculated monthly sales and order volume for January and February 2024.

---

## Level 2: Intermediate SQL Analysis

### High-Value Customers
- Identified customers spending more than $1,000.
- Analyzed completed orders only.

### Top Products by Revenue
- Ranked products based on revenue after discounts.
- Identified best-performing products and categories.

### Customer Segment Analysis
Analyzed:

- Total customers by segment
- Revenue contribution
- Average order value
- Preferred payment methods

---

## Level 3: Advanced SQL Analysis

### Customer Retention Analysis
Classified customers as:

- Retained
- New
- Churned

based on January and February 2024 purchasing activity.

### Product Bundling Analysis
Identified orders containing products from multiple categories.

### Customer Lifetime Value (CLV) Ranking
Calculated:

- Customer total spending
- Order count
- Running revenue total
- Customer spending percentile ranking

using SQL window functions.

### Customer Cohort Analysis
Analyzed customer groups based on registration month and compared revenue growth.

---

## Level 4: Challenge Analysis

### Cross-Category Customer Analysis

Identified customers who purchased from both:

- Electronics
- Clothing

Calculated:

- Electronics spending
- Clothing spending
- Spending ratio
